터치 위치 테스트 앱 - 소스 프로젝트

이 앱은 앱 화면 안에서 손가락을 누르고 이동한 뒤 뗀 위치가 A(왼쪽)인지 B(오른쪽)인지 표시합니다.

중요:
- 이것은 게임 위에 표시되는 오버레이나 게임 입력 자동화 앱이 아닙니다.
- 이 테스트가 성공해도 다른 게임 화면의 터치를 가로채거나 게임에 다시 전달할 수 있다는 뜻은 아닙니다.
- APK는 이 환경에서 빌드하지 않았습니다. Android Studio 또는 호환 Android 빌드 환경에서 프로젝트를 열어 빌드해야 합니다.

열기: Android Studio에서 이 폴더를 프로젝트로 엽니다.
